Test ID: S2-15
Title: Token expiry / long-lived token test
Student: student2 (Privacy & Data Leakage Assessment)
Specialization: Authentication Weaknesses

Objective:
Check whether issued tokens have a reasonable expiry, by decoding a JWT (if used) or testing an old token after a delay.

Input / Attack Scenario:
Log in, inspect token payload for an 'exp' claim (if JWT) or wait and resubmit.

Expected Behaviour:
Tokens expire within a reasonable window (e.g. not indefinitely valid).

The issued JWT contains an exp claim, indicating that the access token has a defined expiration time; no evidence of an indefinitely valid token was observed.

Conclusion:
Token expiry is implemented, although the evidence does not show the exact validity duration or confirm behavior after expiration.

Severity: Medium
