Test ID: S4-14
Title: Denial-of-service via oversized query to the embedding model
Student: student4 (Information Retrieval & Security Assessment)
Specialization: API Security

Objective:
Measure response time and stability when retrieve() is called with an extremely long query string.

Input / Attack Scenario:
A query of ~50,000 characters.

Expected Behaviour:
Request is rejected/truncated quickly with a clear error, not left to consume excessive CPU/time or crash the worker.

Actual Behaviour:

Observations:
The ~50,000-character query was processed successfully and returned results without an error or crash.

Conclusion:
The system accepts oversized queries without apparent input-length validation, indicating potential resource-exhaustion risk.

Severity: Medium
Severity justification: Unbounded input size on an embedding call is a resource-exhaustion / availability risk.
