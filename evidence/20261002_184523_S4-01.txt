Test ID: S4-01
Title: Exact-keyword vs paraphrase retrieval comparison
Student: student4 (Information Retrieval & Security Assessment)
Specialization: Retrieval Accuracy

Objective:
Compare retrieval results for a query using exact wording from a known incident vs a paraphrased version, to measure semantic retrieval quality.

Input / Attack Scenario:
Query A: wording taken directly from a known incident's 'reason'. Query B: a paraphrase using different vocabulary for the same meaning.

Expected Behaviour:
Both queries return the same (or substantially overlapping) top incidents with reasonably high similarity scores.

Actual Behaviour:

Observations:
The exact-wording and paraphrased queries returned completely different top-3 incidents. The exact query returned three Low Repeat Length incidents with similarity 0.2744, while the paraphrase returned three Width Variation incidents with a higher similarity of 0.3339.

Conclusion:
Semantic retrieval is not consistent for this test case. The paraphrase failed to substantially overlap with the incidents retrieved by the exact wording, indicating a retrieval-accuracy weakness for paraphrased queries.

Severity: Informational
Severity justification: A baseline accuracy measurement, not itself a vulnerability — used to contextualize other findings.
