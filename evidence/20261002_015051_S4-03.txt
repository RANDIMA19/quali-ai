Test ID: S4-03
Title: Crafted query to manipulate ranking
Student: student4 (Information Retrieval & Security Assessment)
Specialization: Retrieval Manipulation

Objective:
Test whether stuffing a query with high-frequency incident vocabulary (keyword stuffing) can force an unrelated/old incident to rank artificially high.

Input / Attack Scenario:
A query repeating common incident terms many times ('tension tension tension elongation elongation defect defect...').

Expected Behaviour:
Ranking reflects genuine semantic relevance, not simple term frequency manipulation.
