Test ID: S4-01
Title: Exact-keyword vs paraphrase retrieval comparison
Student: student4 (Information Retrieval & Security Assessment)
Specialization: Retrieval Accuracy

Objective:
Compare retrieval results for a query using exact wording from a known incident vs a paraphrased version, to measure semantic retrieval quality.

Input / Attack Scenario:
Query A: wording taken directly from a known incident's 'reason'. Query B: a paraphrase using different vocabulary for the same meaning.

Expected Behaviour:
Both queries return the same (or substantially overlapping) top incidents with reasonably high similarity scores.
